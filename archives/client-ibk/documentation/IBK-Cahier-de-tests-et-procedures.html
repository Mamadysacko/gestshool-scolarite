Comment utiliser ce document

1. Lisez Prise en main pour comprendre l’ordre logique de l’application.
2. Consultez Procédures quand vous cherchez comment faire une opération (recherche par mot-clé).
3. Déroulez le Cahier de tests dans l’ordre, application ouverte à côté : pour chaque test, suivez les étapes, comparez au résultat attendu et cochez Réussi ou Échec (avec une remarque).
4. L’onglet Synthèse récapitule vos résultats, à imprimer ou exporter.

Vos coches et remarques sont mémorisées dans ce navigateur : vous pouvez fermer et rouvrir le fichier sans rien perdre.
